# Setup Guide

What a new person needs before they can work on the Nextia Clinic project.
Follow the steps in order; each links to the official guide for the details.

## 1. Visual Studio Code

1. Install VS Code for your platform — [download](https://code.visualstudio.com/download).
2. Create a **new, empty profile** dedicated to this project so its extensions and settings stay isolated — [Profiles in VS Code](https://code.visualstudio.com/docs/configure/profiles).

## 2. Claude Code extension

1. Install the Claude Code extension inside your new VS Code profile — [Claude Code in VS Code](https://docs.claude.com/en/docs/claude-code/vs-code).
2. Sign in when prompted to connect the extension to your Claude account — [Claude Code quickstart](https://docs.claude.com/en/docs/claude-code/quickstart).

## 3. GitHub account

1. Create a GitHub account if you don't have one — [creating an account](https://docs.github.com/en/get-started/start-your-journey/creating-an-account-on-github).
2. Turn on two-factor authentication to secure the account — [configuring 2FA](https://docs.github.com/en/authentication/securing-your-account-with-two-factor-authentication-2fa/configuring-two-factor-authentication).
3. Save your 2FA recovery codes in your password manager so you can't be locked out — [2FA recovery methods](https://docs.github.com/en/authentication/securing-your-account-with-two-factor-authentication-2fa/configuring-two-factor-authentication-recovery-methods).

## 4. GitHub organisation

1. Ask an admin for an invite to the **nextia-clinic** organisation, then accept it — [about organisations](https://docs.github.com/en/organizations/collaborating-with-groups-in-organizations/about-organizations).

## 5. GitHub CLI

1. Install the GitHub CLI (`gh`) — [cli.github.com](https://cli.github.com/).
2. Authenticate it with your GitHub account — [gh CLI quickstart](https://docs.github.com/en/github-cli/github-cli/quickstart).

## Working on the project

`main` is protected, so you cannot push to it directly. Create a branch, push it,
and open a pull request — [about protected branches](https://docs.github.com/en/repositories/configuring-branches-and-merges-in-your-repository/managing-protected-branches/about-protected-branches).
